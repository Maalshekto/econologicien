# Configuration pour le projet Éconologicien

Hermes: en travaillant sur ce repo, merci de respecter ces consignes pour garantir la cohérence du blog.

## Standards de rédaction
- Front-matter : Tous les nouveaux articles DOIVENT contenir un `title`, une `date`, `draft` et surtout une `description` de 150-160 caractères pour le SEO.
- Format : Utilisez la syntaxe TOML (`+++`) pour le front-matter si le fichier actuel l'utilise, sinon YAML (`---`) est accepté.
- Style : Ton pédagogique, rigoureux, "Zéro Bullshit". Pas de mysticisme. Citations sources recommandées.

## Automatisation
- SEO : Si une description manque, proposez-en une basée sur le contenu.
- Organisation : Les articles vont dans `content/articles/`.

## Commandes utiles
- Test de build : `hugo`
- Serveur local : `hugo server`
